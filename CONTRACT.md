# ReShow implementation contract

Local-only buildless ES modules. Shared ownership: lead owns index.html, css/styles.css, js/app.js, js/ui.js, js/pages/overview.js, activity.js, reports.js, assets. Data worker owns js/data.js, js/services.js, tests/services.test.mjs, BACKEND_HANDOFF.md. Exhibit worker owns js/pages/exhibits.js, labels.js, css/exhibits.css. Staff worker owns js/pages/staff.js, css/staff.css. No worker spawns agents.

Pages export async function render(container, ctx). ctx = {api, navigate(tab, params={}), params, refresh(), setDirty(boolean)}. Rendering helpers import from ../ui.js: esc(value), icon(name), formatTime(ISO), formatDate(ISO), badge(text,tone='neutral'), toast(text,tone='success'), confirmAction(title,message,button='Confirm') => Promise<boolean>, showDialog(title,html,onMount) => dialog element (native dialog; onMount(dialog); close via dialog.close()), fileToDataUrl(file) => Promise<string>. Pages escape every dynamic interpolation with esc. Use addEventListener, no inline handlers. Rendering is invoked on navigation and demo changes, NOT every store change. Page may ctx.refresh() after actions. Return optional cleanup function. Use .card, .card-head, .grid-two, .stack, .button (.primary,.small,.danger), .muted, .notice (.warning,.info), .field, .form-grid, .badge, .table-wrap, .empty, .actions, .metric, .metrics, .section-title. Specific styles in owned stylesheet. Icons: home,cube,tag,activity,report,users,clock,sun,temperature,lock,check,arrow,edit,plus,scan,info,search,upload,close,card,download.

api async methods (named exports AND api object): getSnapshot(), listExhibits(), saveExhibit(profile), assignExhibit(id), scanExhibitTag(), getLabel(exhibitId), saveLabelDraft(exhibitId,content), sendLabel(exhibitId,content), setLighting(mode), getActivity(filters), generateReport(filters,sections), listReports(), listStaff(), saveStaff(profile), scanStaffCard(), registerCard(staffId,cardId), setCardAccess(staffId,enabled), getAccessLog(), setDemoMode(mode), resetDemo(), settlePending(). subscribe(fn) returns unsubscribe; getDemoMode() sync. mode = normal/loading/empty/offline/pending/failed. Data loading mode delays reads 1800ms. Failed mode rejects device commands AFTER pending visible, plus getSnapshot returns normally. Empty mode lists/activity empty and snapshot contains no exhibits/staff/readings/current assignment. Offline commands fail, never apply. Pending mode queues until settlePending(), after switching normal also can settle. Command Promise resolves operation immediately with status pending; service acknowledges in ~1300ms and emits subscribers. Page workers subscribe and refresh their own operation status carefully without discarding edits. Staff scan and exhibit scan delay 900ms, return {id:'CARD-...' or 'EX-...'}. Device commands persisted and pending recovered as failed on page reload. saveExhibit/saveStaff/saveLabelDraft are normal local saves, not device commands.

Exhibit = {id,name,description,tagId,image:'assets/vase.svg',temperatureMin,temperatureMax,brightnessMin,brightnessMax,warningSeconds,showcaseId:null|'case-01'}. saveExhibit generates id if absent, validates duplicates and numeric ranges; errors include message and optional fields mapping. Assignment command pending then updates showcase/exhibit relations + assignmentHistory on ack. Label content = {title,collection,description,image}. getLabel => {draft:content|null,savedAt:ISO|null,confirmed:{exhibitId,content,acknowledgedAt}|null,history:Operation[],operations:Operation[]}; history includes pending/failed/acknowledged label ops for this exhibit. sendLabel only assigned exhibit, confirmed on ack; validate at ack if assignment changed. Operation = {id,type:'lighting'|'label'|'assignment'|'card',targetId,status:'pending'|'acknowledged'|'failed',requestedAt,acknowledgedAt:null|ISO,payload,error:null|string}. subscribe(fn) fires on change. Page modules should refresh status on subscription when safe.

Staff = {id,name,email,role:'Administrator'|'Operator'|'Viewer',cardId:null|string,cardEnabled:boolean}; pending changes only in operations, confirmed staff unchanged until ack. Access = {id,at,staffId:null|string,cardId,result:'Accepted'|'Denied',details}. No remote access attempt actions. API prevents duplicate enabled card, including reserved pending changes. Scan returns fresh deterministic sample card/tag ids; failed/offline scan rejects.

filters = {showcaseId:'case-01',start:'2026-10-01',end:'2026-10-06',exhibitId:''}; inclusive HKT calendar dates. getActivity => {filters,intervals,events,summary,assignments}. Interval = {id,start:ISO,end:ISO,showcaseId,exhibitId,availability:'recorded'|'missing'|'future',events:number|null,occupiedSeconds:number|null}; hourly exhibition hours 09–17 HKT. Future intervals don't count expected coverage. Event = {id,at,showcaseId,exhibitId,type:'proximity'|'temperature'|'brightness'|'missing'|'label'|'lighting'|'assignment'|'card',details,status}. Summary = {proximityEvents,occupiedSeconds,warnings,missingIntervals,recordedIntervals,expectedIntervals,coveragePercent}. Same aggregator all pages/reports. assignments filtered by overlap and exhibit: {id,exhibitId,showcaseId,start:ISO,end:ISO|null}. generateReport returns persisted immutable {id,createdAt,filters,sections, data:getActivity result,exhibitNames:{id:name}}. sections string array 'history','activity','environment','missing'; missing completeness always included. Exports built from actual report data and sections.

Services are browser-native, can test through Node dynamic import with fake localStorage. No dependencies. localStorage versioned; malformed/unavailable graceful fallback. UI must handle thrown errors with user-facing notice. Async loading shell from app; page operations show busy state.
